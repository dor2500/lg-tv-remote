# TV Anywhere

[English](README.md) | **עברית**

אפליקציה בטלוויזיה מציגה מזהה וסיסמה שמתחלפים כל שבוע. מקלידים אותם באפליקציית הטלפון ושולטים בטלוויזיה מכל מקום.

> **זו גרסת תצוגה מוקדמת, והיא לא גמורה.** עד היום לא הושלם בה חיבור אמיתי על טלוויזיה אמיתית. קרא את [המצב כרגע](#המצב-כרגע) לפני שאתה מסתמך עליה.

## המצב כרגע

| חלק | מצב |
|---|---|
| מזהה וסיסמה שבועיים, הצפנה, חסימת ניחושים חוזרים | עובד בבדיקות אוטומטיות |
| אפליקציית הטלפון | עובדת בבדיקות אוטומטיות בדפדפן מחשב בגודל טלפון. לא נוסתה על טלפון אמיתי |
| השרת המתווך ב-Cloudflare | עובד בבדיקות אוטומטיות בסימולטור המקומי של Cloudflare. עוד לא הועלה לשום מקום |
| אפליקציית LG | מותקנת ונפתחת על LG OLED55C6 אמיתית. שליטה בטלוויזיה **לא** אומתה |
| אפליקציית Android TV | **לא נכתבה** |
| אפליקציית Samsung | **לא נכתבה** |

**מה עוד לא ידוע ב-LG:**

- אם האפליקציה יכולה לשלוט בטלוויזיה שלה דרך הממשק המקומי.
- אם היא ממשיכה לרוץ אחרי מעבר לאפליקציה אחרת. אם לא, היא צריכה להישאר פתוחה בטלוויזיה.
- אם תמונת המסך מגיעה לטלפון.

**מגבלות ידועות:**

- **הדלקת הטלוויזיה:** אפליקציה לא רצה בטלוויזיה כבויה, ולכן אי אפשר להדליק אותה מחוץ לבית.
- **מצב מפתחים ב-LG:** ההתקנה דורשת מצב מפתחים, ו-LG מפעילה אותו לזמן מוגבל. כשהזמן נגמר, האפליקציה מפסיקה להיפתח עד שמתקינים אותה מחדש. אפשר להאריך באפליקציית מצב המפתחים של LG כל עוד נשאר זמן.
- **Samsung:** מפתח דיווח שאפליקציה בטלוויזיה לא מצליחה להגיע לממשק השלט המקומי, ולכן ייתכן שהשיטה הזו לא תעבוד שם.

## הקמה

צריך [Node.js](https://nodejs.org), את [כלי webOS](https://webostv.developer.lge.com/develop/tools/cli-installation) מוגדרים מול טלוויזיה במצב מפתחים, וחשבון [Cloudflare](https://dash.cloudflare.com/sign-up) חינמי.

```bash
git clone https://github.com/dor2500/universal-tv-remote.git
```

```bash
cd universal-tv-remote
```

```bash
npm install
```

```powershell
powershell -ExecutionPolicy Bypass -File anywhere\setup.ps1
```

הסקריפט:

1. פותח דפדפן כדי שתתחבר ל-Cloudflare.
2. מעלה את השרת המתווך ואת אפליקציית הטלפון לחשבון שלך, ומדפיס את הכתובת שלהם.
3. בונה את אפליקציית LG לכתובת הזו, מתקין אותה בטלוויזיה ופותח אותה.

אשר את הבקשה בטלוויזיה בעזרת השלט. אחר כך פתח בטלפון את הכתובת שהודפסה והוסף אותה למסך הבית.

בתוכנית החינמית של Cloudflare יש מגבלות יומיות. הצגת מסך הטלוויזיה צורכת מהן הרבה יותר מלחיצה על כפתורים.

## שימוש

1. פתח את TV Anywhere בטלוויזיה. היא מציגה את המזהה והסיסמה.
2. הקלד אותם באפליקציית הטלפון.
3. הטלוויזיה מציגה שטלפון מחובר.

הפרטים מתחלפים לבד בכל יום שני ב-00:00 UTC. כדי להחליף אותם מיד, לחץ OK בשלט של הטלוויזיה בתוך האפליקציה.

## אבטחה

- **מי יכול לקרוא את החיבור:** הטלפון והטלוויזיה מצפינים כל מה שעובר ביניהם, והשרת המתווך לא יכול לקרוא אותו.
- **ניחוש דרך החיבור:** אחרי 5 סיסמאות שגויות הטלוויזיה חוסמת ניסיונות לזמן שמכפיל את עצמו בכל כישלון נוסף.
- **ניחוש במחשב אחר:** מי שמקליט חיבור בשרת המתווך יכול לנסות סיסמאות אצלו במחשב. בסיסמה יש כ-50 ביט של אקראיות, וההחלפה השבועית מגבילה את משך התועלת שלה.
- **מה הפרטים מאפשרים:** שליטה מלאה בטלוויזיה, כולל כיבוי. שמור עליהם כמו על מפתח לבית.
- **הקוד הזה לא עבר בדיקת אבטחה.**

## איך זה עובד

```text
Phone app  ──wss──►  Relay on Cloudflare  ◄──wss──  App on the TV ──local interface──► TV
           sealed messages the relay can't read
```

הטלוויזיה יוצרת חיבור יוצא לשרת המתווך, ולכן לא צריך לפתוח פורטים בראוטר. המזהה בוחר את החדר בשרת. הסיסמה לא עוברת ברשת: שני הצדדים גוזרים ממנה מפתח ומוכיחים שיש להם אותו מפתח.

| תיקייה | תפקיד |
|---|---|
| `shared/session.js` | פרטים שבועיים והצפנה |
| `agent/` | האפליקציה בטלוויזיה. `core.js` משותף, `adapter-webos.js` הוא החלק של LG |
| `relay/` | `worker.js` ל-Cloudflare, `server.js` לבדיקות או לאירוח עצמי |
| `phone/` | אפליקציית הטלפון |
| `build.js`, `setup.ps1` | בנייה והתקנה |
